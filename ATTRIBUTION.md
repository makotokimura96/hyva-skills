# Attribution and scope

## What this is

A set of unofficial reference skills for AI coding agents, describing Magento 2
Hyvä development. The content was written by reading the official Hyvä
documentation at <https://docs.hyva.io> (plus
<https://hyva-themes.github.io/magento2-hyva-admin/> and
<https://alpinejs.dev>) and distilling it into agent-readable references, with
some claims verified against an actual Hyvä 1.5 / Magento 2.4.7 installation.

It is **not** a copy of the documentation. Each reference file summarises,
reorganises and cross-links; every non-obvious claim carries a link back to the
source page it came from, and the intent is to send you to the official docs
rather than replace them.
